# Pulse Music

A modern, purple-and-black offline music player built with Flutter. Plays every
mp3 / m4a file on the device, with a search + sortable "My Music" library,
Favorites, Playlists, a full "Now Playing" screen with a spinning vinyl-style
disc, and a system notification with playback controls.

This package contains the **Dart source only** (`lib/` + `pubspec.yaml`).
Native Android/iOS project folders are generated by the Flutter tool itself
(`flutter create`), so follow the steps below to drop this code into a real,
runnable project.

---

## 1. Prerequisites

- Flutter SDK installed (`flutter doctor` should be green for at least one
  platform — Android or iOS/macOS).
- A physical device or emulator with some mp3/m4a files on it (the emulator's
  default storage usually has none — you can `adb push` a few test files).

## 2. Create the project shell and drop in this code

```bash
flutter create pulse_music
cd pulse_music

# Replace the generated lib/ and pubspec.yaml with the ones from this package
rm -rf lib
cp -R /path/to/this/lib .
cp /path/to/this/pubspec.yaml .

flutter pub get
```

## 3. Android setup

**`android/app/src/main/AndroidManifest.xml`** — add these permissions inside
`<manifest>`, and the service/receiver inside `<application>` (required by
`just_audio_background` for the lock-screen / notification controls):

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">

    <uses-permission android:name="android.permission.WAKE_LOCK"/>
    <uses-permission android:name="android.permission.FOREGROUND_SERVICE"/>
    <uses-permission android:name="android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK"/>
    <uses-permission android:name="android.permission.POST_NOTIFICATIONS"/>
    <!-- Reading audio files: Android 13+ uses READ_MEDIA_AUDIO, older uses READ_EXTERNAL_STORAGE -->
    <uses-permission android:name="android.permission.READ_MEDIA_AUDIO"/>
    <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"
        android:maxSdkVersion="32"/>

    <application ...>

        <activity ...>
            <!-- keep everything already generated here -->
        </activity>

        <service android:name="com.ryanheise.audioservice.AudioService"
            android:foregroundServiceType="mediaPlayback"
            android:exported="true">
            <intent-filter>
                <action android:name="android.media.browse.MediaBrowserService"/>
            </intent-filter>
        </service>

        <receiver android:name="com.ryanheise.audioservice.MediaButtonReceiver"
            android:exported="true">
            <intent-filter>
                <action android:name="android.intent.action.MEDIA_BUTTON"/>
            </intent-filter>
        </receiver>

    </application>
</manifest>
```

**`android/app/build.gradle`** — set `minSdkVersion 21` or higher (required by
`just_audio_background`).

## 4. iOS setup

**`ios/Runner/Info.plist`** — add:

```xml
<key>UIBackgroundModes</key>
<array>
    <string>audio</string>
</array>
<key>NSAppleMusicUsageDescription</key>
<string>Pulse Music needs access to your music library to play your songs.</string>
```

## 5. Run it

```bash
flutter run
```

On first launch you'll see a "Grant Permission" prompt on the My Music tab —
accept it to let the app read audio files from the device.

## What's implemented

- **My Music**: search bar, sort by adding time / name / play count, infinite
  scroll list, three-dot menu per song (Rename, Play Later, Add to Queue, Add
  to Playlist, Delete, Share).
- **Mini "current playing" banner** just above the bottom nav bar (visible on
  every tab), tap to open the full Now Playing screen.
- **Now Playing**: rotating yellow/black vinyl disc (spins while playing,
  freezes when paused) with the album art inset in the label, favorite star,
  seek bar, Play mode / Previous / Play-Pause / Next, and a three-dot menu
  (Add to Playlist, Sleep Timer, Playback Speed, Edit Song Info, Share, Home
  Screen Widget). Tapping back always returns to the My Music tab.
- **Favorites** and **Playlists** (create, rename, delete, add songs manually,
  remove songs) tabs.
- **System media notification** with play/pause/next/previous, driven by
  `just_audio_background` — appears as soon as something plays and stays live
  in the background.
- Local persistence (favorites, playlists, play counts, renamed titles, sort
  choice, play mode) via `shared_preferences` — no backend needed.

## Known limitations / good next steps

A few options in the three-dot menus are intentionally wired up as clear,
honest placeholders rather than faked, because they need small amounts of
native platform code this package can't safely guess at for your project:

- **Delete**: removes the song from Pulse Music's own library view (and any
  playlists/favorites) but does not delete the file from device storage.
  Actually deleting on Android 10+ requires a user-confirmed
  `MediaStore.createDeleteRequest` intent — a small platform-channel addition.
- **Rename / Edit Song Info**: stored as an in-app display override, not
  written back into the file's ID3/metadata tags. Writing real tags needs a
  tagging package (e.g. one that wraps TagLib) with write permission.
- **Home Screen Widget**: shows an explanatory dialog. Wiring up a real
  home-screen widget needs the `home_widget` package plus native App
  Widget (Android) / WidgetKit (iOS) code.
- **Share**: shares the song's title/artist as text, which works everywhere
  with zero setup. Sharing the actual audio file is a quick upgrade once a
  `FileProvider` (Android) is configured for the project.

## Project structure

```
lib/
  main.dart                     Entry point, background-audio init, providers
  theme/app_theme.dart          Purple & black color palette + ThemeData
  models/                       AppSong, Playlist, PlayMode, SortMode
  providers/
    music_provider.dart         Library, queue/playback, favorites, playlists
    nav_provider.dart           Selected bottom-nav tab
  screens/                      HomeScreen (nav shell), MyMusic, Favorite,
                                 Playlist, PlaylistDetail, AddSongsToPlaylist,
                                 NowPlaying
  widgets/                      MiniPlayerBanner, SongTile, VinylDisc, and all
                                 the bottom sheets / dialogs
  utils/formatters.dart         Duration formatting helpers
```
